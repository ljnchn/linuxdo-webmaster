# 素材来源

`community-sharing-day-v2.png` 是当前使用的 2172 × 724 像素街景，由本项目于 2026-11-11 使用图像生成工具创作并迭代。生成过程基于本项目先前的原创街景，包含咖啡屋、服务器建筑、花园、福利与资源分享屋；没有使用第三方图库、人物照片或外链图片。仅保留当前运行所需的图片。

人物由 `src/world.mjs` 中的 Canvas 绘制逻辑生成。Linux.do 主题标记用于非官方同人游戏。

`src/music.mjs` 的《小站午后》为本项目创作的 16 小节 D 大调合成配乐，76 BPM，通过 Web Audio 生成，不包含第三方录音或外部音源。音乐默认关闭，由玩家点击开启。
