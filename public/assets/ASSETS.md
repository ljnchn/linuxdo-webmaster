# 素材来源

`community-sharing-day-v2.png` 是当前使用的 2172 × 724 像素街景，基于本项目原创街景，于 2026-11-13 使用内置 imagegen 工具重画右侧两栋建筑。福利羊毛为圆顶开放式福利集市，资源荟萃为双层公共资料馆；左侧咖啡屋、服务器建筑和街道沿用原设计。没有使用第三方图库、人物照片或外链图片，仅保留当前运行所需的图片。

重绘提示摘要：保留暖色像素画风、横向视角、街道基线及其余场景；替换两栋建筑的屋顶、体量、立面与内部空间，分别体现福利活动与知识共享。图片不包含人物、界面文字或水印，建筑名称由界面绘制。

人物由 `src/world.mjs` 中的 Canvas 绘制逻辑生成。Linux.do 主题标记用于非官方同人游戏。

`src/music.mjs` 的《小站午后》为本项目创作的 16 小节 D 大调合成配乐，76 BPM，通过 Web Audio 生成，不包含第三方录音或外部音源。音乐默认关闭，由玩家点击开启。
