# v0.8.3 人物事件与界面文案

## 事件入口

按最终要求取消画面正上方的独立事件提示，既不常驻，也不短暂弹出。社区公告建筑保留全部待处理事件汇总，并显示待办数量。开局与结局的必要操作保留。

人物、世界事件均使用各自的场景人物及头顶标记；0 位佬友也可出现持有事件的来访者，不会自动增加成员。人物移动、处理、失效仍使用原来的精确事件标识。场景外的待处理事件在左右逛街箭头上显示数量，点击箭头可向对应方向寻找。公告可一次查看所有未处理事件，赞助人物和领取入口保持独立。

## 文案

事件描述、福利羊毛、资源荟萃及帮助、服务器、成员、存档提示采用简洁的游戏内措辞。奖励仍明确显示星币、内容、氛围及入站人数，不承诺外部资源、实物奖品或现金。音乐来源、离线暂停、租期到期、存储失败、非官方身份等必要说明保留。

文案调整发生在展示层，事件可信快照与旧存档中的原始文字不改，避免已有待办因精确校验失效。经济、事件节奏、行动及后端协议不变。历史需求记录与源码作为技术资料保留。

## 新局默认资料

新玩家默认社区名为 `LINUX DO`，口号为 `Where possible begins.`。本机与服务端首次建档一致。旧存档与重开时原有的自定义名称、口号不被覆盖；创建/重开与资料界面可点击「填入默认名称与口号」，确认保存前仍可编辑。默认填写操作本身不会保存或改变游戏。
