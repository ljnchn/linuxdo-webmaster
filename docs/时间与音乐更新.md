# v0.5 时间与音乐更新

用户反馈：时间流速有问题，希望服务器按天计算，加入可开关的合适背景音乐。

## 已改动

- 默认 1× 调整为 60 秒一个游戏日，2× 为 30 秒，4× 为 15 秒。每个游戏日仍有三个时段。这是本次选择的可调整平衡参数，不冒充最终用户定值。
- 服务器按整天显示，只有完整度过一天才扣除 1 天；月续费仍是 30 天，价格和扩容档位不变。到期优先结束，不能靠当日奖励复活。
- 修正切换速度、开关管理弹窗时丢失时段进度的问题；刷新也保留当前时段的部分进度。离线、后台、弹窗暂停，丢弃未观察到的时间，不补算离线收益。
- 本机试玩由最新打开的页面接管；旧页面暂停并停止写入，避免多页覆盖进度。旧页面刷新后可重新接管。
- v3 存档保留进度、资产、历史和版本修订号，剩余租期不足一天向上补齐一次。已结束的存档不会复活。本机先备份旧存档，后端使用 CAS 迁移。
- 当前日期用“第 N 天”，累计时长用“已运营 N 天”；赞助节点用“运营满 N 天后”，消除开局第 1 天与已完整运营 0 天之间的歧义。事件与赞助的实际游戏日周期不变。
- 补全“组织体验工坊”的“氛围 +2”显示，仅改展示，不改变存档中的既有选项与奖励。
- 原创配乐《小站午后》：76 BPM、D 大调、16 小节循环，柔和旋律、分解和弦与低音。Web Audio 合成，不使用第三方音乐或外链音源。默认关闭，用户点击开启；关闭立即停止，进入后台静音，返回可继续。游戏加速不改变音乐速度。

## 未变更

注册规则、成员增长、事件权重与周期、事件成本和奖励、赞助金额和周期、富可敌国比例、月租价格与排行榜规则均未修改。因为游戏日变慢，同样周期的现实等待时间会增加。

## 验证与边界

独立测试覆盖 60/30/15 秒日长、暂停与变速的累计进度、每日租期扣减、30 天到期、按月续费、存档迁移与原创音频开关。最终 40 项自动测试与 2 项编译后 Worker 测试通过，JavaScript 语法检查与构建通过。

Chromium 实测：桌面与 393px 宽竖屏布局；服务器上午/午后保持整天余量、次日扣 1 天；4× 约 12.3 秒从首日 53.4% 到次日 36.1%，符合 15 秒/天；弹窗前后 39.976% 进度保持；音乐按钮使 AudioContext 在 running/suspended 间切换，刷新默认关闭；按月续费扣 240 星币、加 30 天；旧页面暂停，新页面续费后刷新接管仍保留 520 星币与 43 天租期。

正式 mapp 身份配置和共享榜仍未接通，本机试玩不会上传成绩。浏览器可能因系统静音或自动播放策略不能出声；开关在 API 未成功运行时不伪装播放。真实 iOS/Android 设备尚未实机测试。
