# 小站物语 v0.4 初版实现与验收

日期：2026-11-10。基于本轮新需求与选定的桌面/移动视觉参考。目标是可继续打磨的参赛级初版，不代表赛事验收或获奖承诺。

## 已实现

- 暖白、橙、黑配色和 Linux.do 主题圆标；原创横向像素街景，原创程序绘制人物。不是旧俯视小镇换皮，也不是静态设计稿。
- 桌面常驻操作栏，393px 手机宽度横滑街景、底部导航和事件卡；日夜随游戏时段变化，减少动态偏好生效。
- 0 成员、预付 1C1G 月租开局；续费、扩容、未使用租期折抵、容量上限、租期归零结束。
- 在线自动运行，1×/2×/4× 加速；没有手动推进按钮。离线、后台和管理说明弹窗暂停，主画面的事件卡不中断时间。
- 开放/邀请/关闭注册；每日成长、人物和世界事件共用入站规则。站长可从零成员邀请，关闭注册不接受任何新成员。
- 新成员、优秀文章、富可敌国、捣乱分子事件；独立世界事件类别与虚构新模型发布。
- 有上限的富可敌国成员、定期赞助、手动领取、过期作废。
- 存档与旧版本备份、结束纪念册、重新开局、社区手记、内容板块、可选交互提示音。
- Worker + D1 服务端存档、真实共享榜实现、mapp 签名身份校验、乐观并发和幂等、可信在线时钟。

## 本初版可调参数

不将这些视为用户已确认的最终数值：6秒/时段、3时段/天、30天/月；默认开放注册；开局1000星币预付240后余额760；四档服务器月租240/540/1260/2850，容量60/180/500/1500；邀请最多2人/天；富可敌国上限5%向下取整；每7天产生100星币赞助，14天过期。事件效果见 RULES/事件表。先到期，再结算当日奖励。

榜单暂按存续时间、社区规模分为两个独立排序，不采用未经确认的综合分数。世界事件为本局游戏内虚构信息，不接入现实新闻。

## 实际验证

- JavaScript 语法检查通过。
- 28项引擎、API、鉴权、持久化、并发、Worker及渲染单元/集成测试通过。
- 编译后的 Worker 集成测试通过，包含生成的 ES256 测试 JWT 与 D1 测试数据库；测试身份不是实际 Linux.do 账号。
- 实际 Chromium 桌面布局约1165px，检查第一屏操作可见、事件卡、夜景与续费弹窗。
- 实际浏览器393px嵌套视口检查手机布局，确认图景横向可滚动、主页面无横向溢出、事件卡、运营和加速按钮及底部导航。另检查485px窄窗口。未测试真实iPhone/Android硬件。
- 浏览器实际操作：自动时间与4×加速、人物事件处理、关闭注册后成员保持不增长、月续费扣240并增加30天、赞助全部签收200到账且信箱清空、管理弹窗暂停、世界事件分类、排行榜未接入说明。
- 原需求文档与旧版源码下载保留。旧版来源提交 6efcf76d312f97d240dbb569d9f7ec9ea297a11d，另有本地 Git 回退标签。

## 明确未完成

在本初版验收时，正式 mapp 应用注册与运行配置尚未提供，平台 SDK 打包、真实沙箱身份/网络联调、正式审核仍需完成。当前接入与配置以 `server/DEPLOYMENT.md` 为准。

本机试玩不会上传、迁移或伪装成正式共享排行榜，没有虚构玩家。后端具备实现与自动测试，不等于真实平台用户已可联机上榜。
