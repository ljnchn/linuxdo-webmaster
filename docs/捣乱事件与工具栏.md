# 我要当站长 v0.6.1 · 捣乱事件与工具栏

## 场景交互

- 未处理且未失效的捣乱事件各对应一位原创像素人物：珊瑚色帽子、炭灰外套、手持讨论便签。外观只表达正在争论，不与任何真实身份关联。
- 人物头顶显示 ×。人物身体与标记属于同一个可聚焦的原生按钮，点击或按 Enter / 空格打开该事件，不会误开队列里的其他卡片。多个事件分别绑定实例 ID。
- 调解或请离后，对应人物和 × 一起退出场景。过期或本局结束时同样清除，不留下不能处理的标记。处理后回到场景，其他事件保持待办。
- 原有两种选择及其效果不变：调解氛围 +5 / 内容 +2；请离减少 1 位佬友 / 氛围 +10。没有新增罚款、收益、概率或成员身份。
- 人物位置和命中区由现有事件实时推导，不写入存档，不改变随机序列。原 v4 存档及旧文案快照继续兼容。

## 控件布局

- 底部集中六个图标：社区中心、佬友、内容、服务器、运营设置、音乐。图标有无障碍名称，桌面提供悬浮/键盘提示；手机操作后显示对应管理面板。
- 注册三态、1×/2×/4× 加速移入运营设置面板，顶部保留当前注册状态、速度、氛围与内容概览。打开设置时继续遵守原先的暂停规则。
- 事件通知移到上方，街道上不再叠放运营按钮。手机横滑仍能找到场景另一边的人物。
- 手机主工具按钮 46×46 CSS 像素，顶栏按钮 44×44（极窄屏 42×44）；人物整块命中区至少宽 52、高 118，标记保持明显的 ×。键盘处理后焦点回到场景。
- 服务器续费、赞助信箱、手记、说明、排行入口保留。mapp 共享排行仍待真实平台配置，没有伪装成已接通。

## 验证

- 桌面、393×852 和375×667浏览器视口检查：标记/身体点击、多个事件精准打开、处理后消失、运营设置、音乐切换和横滑位置均核实。
- 多事件浏览器检查使用仅存放于被忽略 `.qa` 目录的隔离测试页面，没有改写旧本机存档，也不会进入发布包。真实移动设备尚未实测。
- 自动化覆盖原事件经济、旧 v4 快照、多事件/到期/结束清理、绘制无副作用、精确事件弹窗、DOM节点复用和键盘焦点恢复。
