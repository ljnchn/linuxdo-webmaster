# v0.7.0 经营升级与安全重开

## 实现

本轮仅更新原《我要当站长》，沿用原站点与 v4 存档键。另两个独立卡牌项目不变。

- 精简首页装饰说明、设置与帮助中的重复段落，保留暂停、租期到期、事件效果、虚拟资源、共享榜未接入等必要说明。
- 底部爱心直达经营方向，不必进入设置或内容二级页。桌面有悬浮提示，手机保留足够触控区与无障碍名称。
- 开局可填社区名称（1–24字符）与口号（0–40字符）；后续点场景顶部社区资料或设置修改。桌面和手机均展示，超长视觉省略但可点开看完整内容；空口号不占文字行。使用转义和 textContent 防止名称被作为 HTML 执行。
- 设置和结束页均可重开，先明确确认。取消不清空进度；确认后新局0佬友、1C1G、760星币、30天租期，继承名称与口号，新种子、新挑战规则，等待再次开站。
- 本机重开与恢复前追加完整备份，含状态、速度和时段内时间进度。写入后读回验证，失败则不重开；历史备份不自动删除。可下载当前/历史存档，可恢复备份，恢复前也保存当前局。浏览器存储容量有限，满额会阻止安全重开；不承诺浏览器被清理后仍能恢复，建议下载留存。
- 平台后端每身份原子保留最近前局，与 revision CAS、幂等操作同事务提交；失败回滚、重试不重复替换；主动弃局不计入已完成历史。下载备份不等于可导入可信排行榜。真实 mapp 配置仍未提供，本网站继续本机试玩。

## 街道建筑追加

按用户后续更正，新增的是场景中独立的「福利羊毛」「资源荟萃」建筑，不是文档模块。原公告、咖啡屋、服务器与文档共建保留；街道向右延长，加入羊图标礼物铺和书图标资源馆。福利建筑打开既有赞助信箱，资源建筑打开既有内容与氛围面板，不另加经济机制。6处建筑均提供可聚焦点击区域；左右箭头和手机横滑可逛全街，默认仍在咖啡屋。未删除文档、用户内容或存档。

## 难度

旧 v4/v3 局默认原局规则，资产、概率、事件与进度不重算。新建或确认重开后启用挑战规则，具体维护费、方向数值、质量流失、捣乱后果和多种子模拟见《挑战模式平衡》。维护不足没有隐藏债务或随机立即终局；服务器归零仍是结束条件。免费方向与事件选项提供恢复路径。
