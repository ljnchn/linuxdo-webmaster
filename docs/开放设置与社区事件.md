# v0.8.2 开放设置与社区事件

## 界面调整

- 「开放状态」改成紧邻心形经营方向的单个图标按钮。悬停或键盘焦点提示名称和当前状态，点击打开三态设置。当前图标和小色点随开放/邀请/关闭更新，手机另外显示当前状态短文字，不依赖悬停。邀请使用人物加号而非信封。
- 三态弹窗显示完整名称、规则说明、选中高亮和勾选。切换即时生效，弹窗暂停计时；关闭后焦点回到原入口。
- 左上不再显示「挑战经营」或「原局规则」标签。只是移除文字，不改当前局的难度或经济。
- 原右侧事件入口移到场景上方中间，突出事件图标、数量、标题和最早剩余处理时间。没有事件时也保留低调的社区事件入口。
- 事件入口只管理人物/世界事件，不切换成赞助入口，没有事件信箱、信件或签收概念。独立金币人物和资金按钮仍可查看并领取赞助，赞助面板改为「来自佬友的支持」「全部领取」，旧日志只在显示时将赞助信件单位转为「份」。

## 不变项

引擎、角色运动、时钟、事件节奏、建筑活动、注册限制、赞助额度和过期、存档键及后端保持不变。没有新增分享或串门，排行榜继续隐藏，原站继续私有。

## 可访问性与验证

开放按钮保留 aria-haspopup=dialog、完整可访问名称和当前态。三态使用原生按钮、aria-pressed 和关联说明；重复刷新不替换已存在的选项节点。社区事件入口采用渲染内容缓存，避免浏览器标准化 SVG 标签导致重复重建和焦点丢失。弹窗内部切换或更新不覆盖原入口的焦点记录。

桌面及 320×852、375×667、393×852 视口已实际检查。开放、邀请、关闭可切换；手机显示短状态，关闭设置后回到入口，键盘焦点显示完整提示。事件处理后计数和标题更新，入口重建后关闭弹窗仍回到事件按钮。人物标记保留，赞助领取独立测试成功。旧存档可读取，开放状态在刷新后保留，已结束的存档不能改注册状态。此轮仅改界面，不改存档格式或经营数值。
