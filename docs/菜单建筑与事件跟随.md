## 人物与标记同步

场景使用 getSceneActors 的稳定人物 ID 和同一帧整数坐标绘制人物，并通过 createWorld 的第四参数把同一数组送给原生按钮。事件按钮保存精确事件 ID，处理前卡不会让剩余人物改绑另一卡。DOM 节点保持不变，只更新坐标和说明；键盘焦点不因动画不断丢失。

普通人物、事件人物与赞助人物共享场景坐标。移动标记和人物可点，事件处理/到期、赞助领取/过期、游戏结束时移除。减少动态效果偏好下人物和标记静止。动画只是表现，不改经营状态或随机种子。金币点击仍为独立赞助信箱，福利建筑不代领赞助。

## 兼容与撤回范围

沿用 little-community-story:v4 存档键。旧 v3/v4 存档及备份继续保留，新增活动账本为可选字段，旧事件严格快照兼容不变。自动时钟、加速、租期、注册限制、赞助节奏、现有经济不变；只扩充人物事件池，没有提高出现频率。

排行榜入口按要求隐藏，相关代码与服务端成绩保留。用户随后决定暂不做分享链接，本轮不包含串门、分享链接或访问权限更改，继续私有部署。真实平台身份仍未配置，不把离线测试称为真实多人联通。

## 验证

自动化检查覆盖菜单唯一入口与状态、活动原子性/存档/冷却、旧档兼容、事件生成/处理/过期、同帧整数位置、减少动态效果、稳定事件映射、重复点击和请求迟到保护。
