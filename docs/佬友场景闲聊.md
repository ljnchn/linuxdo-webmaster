# 我要当站长 v0.6.2 · 佬友场景闲聊

- 场景中真实显示、位于当前视野内的佬友会偶尔说一句原创短话。30句台词围绕文档、开源、代码、模型、分享、咖啡和休息，少量台词对应上午、午后或夜晚。
- 每次最多显示一个气泡，约5秒后收起，再空出8～15秒。开始或恢复游玩后等3～6秒；屏幕中找不到能安全放置气泡的佬友时保持安静。
- 气泡跟随说话人物，保持在视野内，并避让人物事件 ×、问号、金币及各个状态和工具区域。窄屏横滑会重算位置，离开视野的说话者不留下悬空气泡。
- 0佬友、未开站、弹窗暂停、后台、结束或关闭闲聊时不发言；恢复时不补发离线台词。站长及事件占位角色不参与闲聊。
- 台词使用独立的展示随机源、真实秒数，不读取或推进游戏随机数，不受1×/2×/4×影响。没有新经营收益、处罚或存档字段。
- 运营菜单可关闭「场景闲聊」。开关单独记在当前浏览器，不改原游戏存档。关闭不影响音乐。
- 气泡不响应点击、不夺取焦点、不通过屏幕阅读器自动播报；手动阅读时标识为「游戏角色闲聊」。减少动态效果偏好下，文字无动画并跟随静止人物。
- 所有台词均为虚构角色在游戏中的装饰性对话，不代表玩家发布真实帖子或向 Linux.do 发送消息，没有新增网络请求。

浏览器检查使用桌面和两种移动布局模拟；真实iOS/Android设备未测试。mapp共享榜的配置状态未改变。
