# v0.8.1 开放状态工具栏

按用户反馈，把原左上角「开放状态」整体移到下方爱心经营方向按钮右侧，与同一工具栏并排。三个状态保持可见、一键切换，显示图标与短文字，当前选中状态高亮；完整名称、规则提示和 aria-pressed 语义不变。没有弹出二级菜单。

工具栏统一为暖白/浅金像素按钮、细边框和底边阴影。桌面按钮高 48 像素；常见手机按钮至少 44×48 像素。极窄（369px及以下）手机隐藏底栏重复的「佬友」「服务器」按钮，顶部对应状态按钮继续可点击，保留所有功能，给开放状态足够空间。

仅调整界面结构和样式。引擎、时钟、事件、建筑、注册规则、存档与后端不变。沿用原私有站点，没有新增分享、串门或排行榜入口。

实际浏览器检查：桌面 1180×765、375×667，以及 320×852 / 393×852 的手机尺寸页面。375px 所有八个工具按钮同排可见，开放状态按钮为 44×48；320px 三态为 46×48，保留顶栏佬友/服务器入口。鼠标点击、键盘 Enter 切换及刷新后邀请状态保留均验证，经营方向中的内容/氛围继续正常显示。手机尺寸测试为桌面浏览器 iframe，不等同物理手机设备。
