# 我要当站长

Linux.do 主题的像素社区经营微应用，当前版本 **0.16.3**。从零佬友开始经营社区，处理人物事件、开展建筑活动、续租与升级服务器，并解锁跨局成就。事件取材于 L 站日常：开放注册、举报队列、公益站 502、模型发布、文档共译、旧帖考古，以及那些熟悉又头疼的推广帖。

全站排行榜按社区规模或运营天数展示每位玩家的最佳成绩，附 Linux.do 名称、用户名、头像及社区名称。后端使用 **Node.js 24 + SQLite**，通过 Linux.do 官方签名验证身份。沙箱与正式版使用同一运行包、同一后端及同一份玩家进度。

街景目标卡引导下一步成长。未开放建筑显示施工围网，开放后出现工作人员；筹备活动会摆放物资，举办时出现桌席与参与者。社区成长增加路人与街景设施。

地面租约剩余价值可以抵扣建设费。进入无限模式后，太空数据中心永久运行，人口继续增长，本局不再换回地面服务器。经营方向、质量流失、赞助、活动、荣誉和排行榜继续结算。

- 免费活动立即完成。徽章抽奖、仓库共读需 2 天，课程共学和跨站集市需 3 天，开源大会需 4 天。集市花 300 刀，最多迎接 80 人。大会花 1,800 刀，最多迎接 400 人。开办时扣费，完成时按当日注册状态与容量结算。
- Neo、神墨、诸葛亮各有六章主线，相邻章节分别间隔 2、2、5、9、14 个游戏日。第三章成为骨干，分别增加福利氛围、资源内容或降低付费资源活动费用。旧存档按原选择和游戏日期接续第四章，建筑面板也可直接找当值骨干交谈。三位角色的名字与头像取自 [Linux.do 管理团队](https://linux.do/about)。
- 主线之后，Neo 每 10 天邀你轮值，神墨每 12 天邀你打理资料馆，诸葛亮每 14 天邀你回实验室。每人三件回访轮换，办理后开始计算下一次，晚到仍可赴约。回访计数与主线章节分开；详情保留六章选择和最近一次回访，人物会在街上闲聊。太空无限模式照常推进。
- Lv.5 可免费确定本局特色：迎新友好每日额外招新 1 人，每满 500 人再加 1，最高额外 50 人；内容为王每天内容 +1、有问必答每天氛围 +1。本局只能选一次。
- 每栋活动建筑完成 3 / 8 次活动升至专长 Lv.2 / Lv.3，福利活动额外增加 1 / 2 氛围，资源活动额外增加 1 / 2 内容。
- 每满 30 天评选月度荣誉。8,000 人且氛围、内容均达 80，可获「跨区共建」。万人成就「万家灯火」及建成太空数据中心的「轨道上线」均跨局保留。
- 资金入口显示日均收支，服务器选择时同步显示扩容后的预估。租金按天摊销仅用于比较，实际仍在购买时预付；赞助必须主动领取，估算不含事件收益。

旧存档无需重开。升级后按已有可信进度补判游戏徽章，未记录的历史活动不追溯。后端启动时自动迁移上电视偏好字段，平台运行包与后端需配套更新。

## 本地开发

需要 Node.js 24+，微应用打包需要 Bun。项目无须安装运行依赖。

```sh
bun run dev
bun run check
bun run test
```

访问 `http://127.0.0.1:4173`。默认端口为 4173（与后端开发模式的跨域来源一致）；需要换端口时用 `bun run dev -- --port 3000`，或设置 `PORT` 环境变量。本机网页预览使用浏览器存档，不上传为全站成绩。测试脚本在 `tests/` 目录执行，覆盖游戏规则、存档迁移、平台身份、接口、并发、排行榜和成就。
