# 我要当站长 · I Want to Be a Webmaster v0.9.2

0.9.2 新增全站排行榜与 8 项跨局成就，由服务器保存、校验成绩。
后端由应用维护者自行部署，域名为 `https://linux-do-webmaster.rmb.run`。
运行 `bun run pack` 生成统一运行 ZIP，沙箱和正式版使用同一个包、同一个后端，详见 [打包说明](mapp/README.md)。
同一账号在两个环境共用存档、成就与排行榜，无需设置环境开关。本机网页预览使用 `bun run dev`。

Linux.do 主题的像素社区经营游戏。让社区运营得更久，让更多人相遇。

## 本版实现

- 开局或点社区名可自定义名称与口号；底部爱心一键打开经营方向。
- 设置提供确认重开、存档导出与备份恢复。本机备份追加保存，存储失败阻止重开；服务端原子保留最近前局。
- 新局启用挑战规则：规模维护费、质量流失、未处理捣乱后果及免费友善维护。旧局不追溯改经济。详见 [挑战模式](docs/挑战模式平衡.md)。

- 文档共建实体建筑改为休息花园；福利羊毛铺和资源荟萃馆重新绘制，分别提供福利/抽奖与软件、开源、视频、书籍活动。旧内容数据保留。
- 主菜单移除社区内容入口，内容/氛围数值归入经营方向；开放状态图标与底部心形方向按钮并排，悬停/焦点显示当前态，点击打开三态设置。
- 每栋建筑独立 7 游戏日活动冷却，至少 1 位佬友，显示费用和收益；活动收益计入本局社区，详见 [建筑活动](docs/建筑活动.md)。
- 新增 6 种带 ! 的人物求助/事务，人物总池为 10 种；?、!、×、金币与对应人物同帧移动和点击。原事件节奏不变。
- 保留用户提供的场景闲聊；恢复全站排行榜入口，按社区规模或运营天数查看每位玩家的最佳记录。成就解锁后跨局保留。
- 整屏原创横向像素街景，无外围经营台框架；状态与开放控制浮在场景上，加速位于设置，手机横滑探索。正上方不再显示独立事件提示；人物标记处理具体事件，社区公告汇总全部待办。
- 0 佬友，1C1G 月租服务器开局，续费、扩容、到期立即结束。
- 服务器租期以整天显示与扣除，每完成一天扣 1 天；按月续费与价格不变。
- 原创 Web Audio 背景音乐《小站午后》，默认关闭，点击开关，后台静音。
- 在线自动运行，1× / 2× / 4× 加速；离线、后台及管理弹窗暂停。
- 开放、邀请、关闭注册统一约束所有入站路径。
- 新佬友、优秀文章、富可敌国、捣乱分子人物事件；10 类独立虚构世界事件，按既有 12 天周期轮换。
- 固定周期赞助、手动签收、严格过期和富可敌国占比上限。
- 独立引擎，服务端校验时钟、身份、重复操作与版本；真实 D1 排行榜实现。

## 运行与检查

Node.js 24+，无运行依赖。

```sh
npm run check
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 4173
```

`npm run dev` 为本地网页预览，构建输出 Cloudflare Worker `dist/server/index.js` 和数据库迁移 `dist/drizzle/`。部署步骤见 [后端部署说明](server/DEPLOYMENT.md)。

## 数据与接入边界

此次更新沿用原网站与存档键。旧 v4/v3 事件显示快照按精确历史定义兼容，不清空资产、进度或玩家自取的社区名称。

网站默认是本机试玩。浏览器存档不上传，不能导入正式共享榜。v3 存档保留进度、资产与修订号，未满一天的租期向上补齐一次；本机迁移前备份原存档。旧 v1/v2 存档先备份，再按新规则开局，不把旧经济数值混入新版。

后端支持 Node.js 24 + SQLite，或 Cloudflare Worker + D1，源表迁移见 `drizzle/`。应用 ID 与后端 HTTPS 域名已填入。成就与开站状态使用 `0002_player_achievements.sql`，统一玩家数据使用 `0003_shared_players.sql`。平台 SDK 接入和本地沙箱回归已实现，真实平台联网验收仍需部署后执行。

具体步骤见 `server/DEPLOYMENT.md`、`mapp/manifest.template.json`。玩家使用平台身份，榜单由服务器校验成绩。

## 试玩假设

`src/engine.mjs` 的 `RULES` 是单一参数来源。20 秒/时段（默认 60 秒/游戏天）、3 时段/天、30 天/月；开局 1000 星币预付 240 后余额 760；邀请 2 人/天；富可敌国 5% 向下取整；每 7 天赞助 100 星币，14 天失效。以上是可调整的初版平衡参数，不是用户已确认的最终数值。
