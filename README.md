# 我要当站长

Linux.do 主题的像素社区经营微应用，当前版本 **0.12.0**。从零佬友开始经营社区，处理人物事件、开展建筑活动、续租与升级服务器，并解锁跨局成就。事件取材于 L 站日常：开放注册、举报队列、公益站 502、模型发布、文档共译、旧帖考古，以及那些熟悉又头疼的推广帖。

全站排行榜按社区规模或运营天数展示每位玩家的最佳成绩，附 Linux.do 名称、用户名、头像及社区名称。后端使用 **Node.js 24 + SQLite**，通过 Linux.do 官方签名验证身份。沙箱与正式版使用同一运行包、同一后端及同一份玩家进度。

## 社区等级与建筑

福利羊毛采用开放式福利集市，资源荟萃采用双层公共资料馆。建筑及内部活动按社区等级开放：

| 等级 | 达到的佬友数 | 新开放内容 |
| --- | --- | --- |
| Lv.1 | 0 | 社区起步 |
| Lv.2 | 10 | 福利羊毛、整理限免清单、Neo 的故事 |
| Lv.3 | 30 | 资源荟萃、软件分享、神墨的故事 |
| Lv.4 | 60 | 社区徽章抽奖、书籍共读、诸葛亮的故事 |
| Lv.5 | 120 | 开源仓库共读、本局社区特色 |
| Lv.6 | 250 | 视频课程共学 |
| Lv.7 | 500 | 知识之城 |
| Lv.8 | 750 | 小有名气 |
| Lv.9 | 1000 | 千人同行 |
| Lv.10 | 1500 | 繁荣都会 |

已获得的等级在本局保留，人数下降不会重新锁定；重开后从 Lv.1 开始。旧存档按当前规模和保留的历史规模识别等级，在后续操作中保存。活动仍受每栋建筑 7 天冷却、资金与入站条件约束，服务端执行相同解锁校验。

街景目标卡引导下一步成长。未开放建筑显示施工围网，开放后出现工作人员；筹备活动会摆放物资，举办时出现桌席与参与者。服务器扩容增加机柜，社区成长增加路人与街景设施。

人物头上的金币可直接领取全部待领赞助；事件问号、叹号与故事提示可点击交谈。工作人员头上的加号可安排建筑活动，时钟显示筹备或冷却剩余天数。街景两侧箭头会提示画面外可办的事项。

挑战规则按服务器档位收取基础维护费 1 / 3 / 8 / 20 刀，每人每日另计 0.30 / 0.32 / 0.34 / 0.36 刀（总人数费用向下取整）。口碑增长随当前规模提升，500 人后倍率封顶；赞助者增长也随规模调整，仍受 5% 身份上限约束。低质量流失、未处理争论、租期与活动冷却规则不变。

- 免费活动立即完成；徽章抽奖、仓库共读需 2 个游戏日，课程共学需 3 天。开办时扣费，完成时发放成果，冷却从开办起算。离线、后台与弹窗暂停；租期到期优先于活动结算。
- Neo、神墨、诸葛亮各有三段故事，阶段之间等待 2 天，早期选择影响后续文本和结局收益。成为骨干后分别增加福利氛围、资源内容，或降低付费资源活动费用。三位角色的名字与头像取自 [Linux.do 管理团队](https://linux.do/about)，头像随应用打包，不依赖外链。
- Lv.5 可免费确定本局特色：迎新友好每天自然入站 +1、内容为王每天内容 +1、有问必答每天氛围 +1。本局只能选一次。
- 每栋活动建筑完成 3 / 8 次活动升至专长 Lv.2 / Lv.3，福利活动额外增加 1 / 2 氛围，资源活动额外增加 1 / 2 内容。
- 每运营满 30 天评选温暖街区、知识灯塔、共建之城。人物故事、活动和月度荣誉另有 6 项跨局成就。重开会清除本局项目、故事与特色，保留服务端成就和前局备份。
- 资金入口显示日均收支，服务器选择时同步显示扩容后的预估。租金按天摊销仅用于比较，实际仍在购买时预付；赞助必须主动领取，估算不含事件收益。

旧存档无需重开，不追溯补发旧活动的完成次数。新增进度仍保存在现有状态 JSON 中，无需新增数据库迁移；前后端需一同更新到本版本。

## 本地开发

需要 Node.js 24+，微应用打包需要 Bun。项目无须安装运行依赖。

```sh
bun run dev
bun run check
bun run test
```

访问 `http://127.0.0.1:4173`。默认端口为 4173（与后端开发模式的跨域来源一致）；需要换端口时用 `bun run dev -- --port 3000`，或设置 `PORT` 环境变量。本机网页预览使用浏览器存档，不上传为全站成绩。测试脚本在 `tests/` 目录执行，覆盖游戏规则、存档迁移、平台身份、接口、并发、排行榜和成就。

## 配置位置

| 内容 | 文件 |
| --- | --- |
| 人物冒泡台词、间隔 | `src/ambient-chat.mjs` 中的 `CHAT_LINES`、`CHAT_TIMING` |
| 事件、结果文案、经济规则、建筑活动 | `src/engine.mjs` |

| 成就条件 | `src/achievements.mjs` |
| 场景人物与建筑位置 | `src/world.mjs` |
| 界面与交互 | `src/app.mjs`、`src/life-ui.mjs`、`app.css` |
| 平台权限、后端端点 | `mapp/manifest.template.json`、`mapp/config.mjs` |
| 后端环境变量示例 | `server/.env.example` |
| 数据库迁移 | `drizzle/*.sql`，由 Node 服务启动时自动执行 |

旧存档迁移与原操作重试记录继续保留，防止升级丢失进度或重复扣费。测试中的旧版本数据用于验证兼容性。
